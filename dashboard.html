Physical Hardware & 3rd Party Tools

Hardware Reference Guide

Use this matrix to identify and isolate physical component failures before dispatching a technician.

  • Power: Inspect PSU, wall sockets, AC adapters, 24-pin/EPS connections, and motherboard capacitors (bulging/burns).
  • Storage: Verify NVMe/SATA connections, check boot partitions (GPT/MBR), test with external USB drives.
  • Memory: Check DDR generation compatibility, RAM clock frequencies, slot pairing, and POST beep codes.
  • Thermals: Monitor CPU/GPU cooling fans, liquid cooler pumps, thermal paste integrity, and fan curves.
  • Motherboard: Inspect standoffs, replace CMOS battery (CR2032), verify PCIe slots, update BIOS/UEFI.
  • Peripherals: Test dedicated/iGPUs, swap display cables (HDMI/DP), check NICs, audio jacks, and powered USB hubs.
